# For Wiwi — Memory Book

A responsive flipbook website with six supplied photos and a reserved music player.

## Files
- `index.html`
- `style.css`
- `app.js`
- `assets/photos/photo-01.jpg` through `photo-06.jpg`
- `assets/music/` (reserved for the MP3)

## Add the song later
When you have an MP3 file that you are allowed to use, upload it to:
`assets/music/halet-hob.mp3`

The music player on the song page is already linked to that exact path.

## Publish on GitHub Pages
Upload the CONTENTS of this folder to the root of your existing repository, replacing the old `index.html`, `style.css`, and `app.js`. Keep the `assets` folder and its subfolders. Then wait for GitHub Pages to redeploy.

Note: photos in a public GitHub repository are publicly accessible. Only upload images you have permission to share.
